# Journal des arbitrages

Décisions de l'utilisateur, avec ses mots quand ils fixent un sens, et leur effet. Le contenu admis est dans [[theisme-cadre]], les statuts dans [[theisme-registre]].

| Sources | Toute connaissance est sourcée ou démontrée ; le modèle ne sert qu'à raisonner.
