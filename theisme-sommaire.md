# Examen du théisme — sommaire

Examen, module par module, des prémisses qui fondent l'existence d'un Dieu bon et personnel, et de ce qu'implique leur refus. Chaque énoncé est démontré ou sourcé ; aucune conclusion n'est fixée d'avance.

## Où en est l'examen

M0 est rédigé (2026-11-01) : la logique seule ne tranche pas, et, sous l'hypothèse P1, la question se ramène à une prémisse sur ce qui est possible. La vérification de cohérence globale est faite et ses points sont statués ; M0 passe devant la population, puis M1.

## Organisation

- `methode/` : comment on travaille et ce qui a été décidé.
- `socle/` : ce sur quoi tous les modules reposent.
- `modules/` : une note de résultats par module, `theisme-mN-resultats`.
- `annexes/` : les preuves mécaniques.
- `population/` : le formalisateur, le synthétiseur, le vérificateur formel et les quatre philosophes, un profil par agent ; leurs objections jugées sont consignées dans `modules/theisme-mN-debat`.

Chaque énoncé vit à un seul endroit ; les autres notes y renvoient.
